# Release 0.2.13

## Fixes
- Live reload of `rules.json` now works. The file lives in the hidden `.obsidian` folder, where Obsidian reports changes only through a low-level event the plugin was not listening to, so edits to the file were not picked up until a manual reload.
- Deleting a character (Backspace) or pasting text that leaves a trigger at the cursor no longer expands it. Expansion now happens only while typing.
- `\polylongdiv{x^{2}+1}{x-1}` and other arguments with nested braces are now recognised, and the expansion no longer overwrites text typed while the division module loads.
- Expansion replaces only the trigger instead of rewriting the whole line, so other cursors and the undo history are left alone, and a multiline expansion is a single undo step.

## New
- **Expand on space** (Settings, off by default): a trigger ending in a letter expands when you press space after it, so you can type `\textbf` without `\text` expanding first. The space is consumed. Triggers ending in a symbol, such as `\lim_`, still expand immediately.

## Other
- The two start-up notices ("external rules found" and "N active rules") are shown only when Debug logs is on.
- Triggers are normalised once when rules load rather than on every keystroke.
- Development: added a Makefile (`make check`, `make install`, `make qa`) and `scripts/qa-desktop.mjs`, which runs the automated part of the QA checklist in a running Obsidian.

Existing `rules.json` files keep working unchanged.
